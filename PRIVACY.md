# Privacy Policy — JSON Viewer

**Last updated:** 16 August 2026

JSON Viewer is a local file viewer and editor. This policy describes what the app does with your
data. It is short because the app does very little.

## What the app collects

**Nothing.** JSON Viewer does not collect, transmit, or store any personal data on any server.

- There is no account, no login, and no registration.
- The app contains no analytics, telemetry, crash reporting, or advertising SDKs.
- The app makes no network requests. It has no internet permission on Android.

## What stays on your device

Two kinds of data are stored locally and never leave the device:

1. **The files you open.** Their contents are read into memory to display and edit them, and written
   back only when you tap Save. On Android the file is accessed in place through the document you
   selected. On iOS the file is imported into the app's own storage, because iOS does not grant
   apps lasting access to files elsewhere on the system.
2. **A list of recently opened files.** Names, sizes, and the location of the last ten files you
   opened, so they can appear on the home screen. You can remove any entry with the × button next
   to it, and clearing the app's data removes the list entirely.

This local data is excluded from Android cloud backup and device transfer.

## Permissions

- **Android:** no runtime permissions are requested. Files are read through the system document
  picker, which grants access only to the file you pick.
- **iOS:** no permissions are requested. Files are read through the system document picker.

## Sharing

The Share button hands the selected file to another app you choose from the system share sheet.
What happens to the file after that is governed by the receiving app's own privacy policy. Nothing
is shared unless you explicitly initiate it.

## Children

The app is suitable for all ages and does not collect data from anyone, including children.
